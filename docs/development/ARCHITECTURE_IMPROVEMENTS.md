# Expeta 架构改进追踪文件

## 概述

本文档记录了 Expeta 项目的架构改进建议和实施追踪。这些改进旨在提升代码质量、性能、安全性和可维护性。

## 改进优先级

🔴 **高优先级** - 影响系统稳定性和安全性的关键问题  
🟡 **中优先级** - 影响开发效率和代码质量的问题  
🟢 **低优先级** - 优化和增强功能

## 架构改进项

### 1. 安全性增强 🔴

#### 1.1 API 密钥管理
- **问题**: API 密钥可能在日志中泄露，缺少安全的配置管理
- **影响**: 高风险 - 可能导致密钥泄露
- **解决方案**:
  ```python
  # 使用 pydantic 的 SecretStr
  from pydantic import BaseSettings, SecretStr
  
  class Settings(BaseSettings):
      openai_api_key: SecretStr
      qdrant_api_key: SecretStr
  ```
- **状态**: ⏳ 待实施
- **预计工时**: 4小时

#### 1.2 输入验证
- **问题**: 缺少对用户输入的验证和清理
- **影响**: 中风险 - 可能导致注入攻击或系统错误
- **解决方案**: 使用 Pydantic 模型进行输入验证
- **状态**: ⏳ 待实施
- **预计工时**: 8小时

#### 1.3 文件路径安全
- **问题**: 文件操作没有路径遍历保护
- **影响**: 中风险 - 可能访问意外的文件
- **解决方案**: 实现安全的路径验证函数
- **状态**: ⏳ 待实施
- **预计工时**: 2小时

### 2. 错误处理和异常管理 🔴

#### 2.1 统一异常层次
- **问题**: 缺少自定义异常类型，错误处理不一致
- **影响**: 影响调试和错误追踪
- **解决方案**:
  ```python
  # common/exceptions.py
  class ExpetaError(Exception):
      """Base exception for Expeta"""
  
  class ConfigurationError(ExpetaError):
      """Configuration related errors"""
  
  class LLMServiceError(ExpetaError):
      """LLM service related errors"""
  ```
- **状态**: ⏳ 待实施
- **预计工时**: 6小时

#### 2.2 重试机制标准化
- **问题**: LLM 调用的重试逻辑在多处重复实现
- **影响**: 代码重复，维护困难
- **解决方案**: 使用 tenacity 库实现统一的重试装饰器
- **状态**: ⏳ 待实施
- **预计工时**: 4小时

### 3. 性能优化 🟡

#### 3.1 实现缓存层
- **问题**: 重复的 LLM 调用和数据库查询没有缓存
- **影响**: 性能低下，成本增加
- **解决方案**: 
  - 使用 Redis 或内存缓存
  - 实现智能缓存失效策略
- **状态**: ⏳ 待实施
- **预计工时**: 12小时

#### 3.2 批处理优化
- **问题**: 实体处理没有批处理优化
- **影响**: 大规模项目处理缓慢
- **解决方案**: 实现批处理和并发控制
- **状态**: ⏳ 待实施
- **预计工时**: 8小时

#### 3.3 向量数据库查询优化
- **问题**: 向量查询没有使用索引优化
- **影响**: 查询性能随数据增长下降
- **解决方案**: 创建适当的 HNSW 索引
- **状态**: ⏳ 待实施
- **预计工时**: 4小时

### 4. 架构和代码质量 🟡

## 技术债务清单

### 高优先级债务
1. **重复代码**: 异步函数包装器重复 (common/async_utils.py)
2. **硬编码配置**: 默认值散布在代码中
3. **日志泄露**: 敏感信息可能出现在日志中
4. **异常处理**: catch-all 异常处理过于宽泛

### 中优先级债务
1. **模块耦合**: knowledge 和 reasoning 模块相互依赖
2. **测试覆盖**: 核心功能测试不足
3. **配置分散**: 配置管理不集中
4. **性能问题**: 大规模项目处理缓慢

### 低优先级债务
1. **代码注释**: 复杂逻辑缺少注释
2. **文档更新**: README 和文档过时
3. **命名一致性**: 部分变量和函数命名不一致
